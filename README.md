
# Palmistry Master AI

A mobile-friendly traditional palmistry interpretation website.

## Features
- Palm photo preview
- Left, right and both hands
- Seven traditional palm line categories
- English, Urdu and Hindi
- Copy and print reports
- Responsive mobile design
